# Nach Erreichen des 25-USD-Ziels

1. BMC-/Sponsors-Goal schließen oder als erreicht markieren  
2. Dank posten (Texte in `FUNDING_CAMPAIGN.md`)  
3. README-Block ersetzen durch:

```markdown
> **Spendenziel erreicht — danke.**  
> Der einmalige Aufruf ist geschlossen. Reguläre Sponsoren bleiben willkommen:  
> [Buy Me a Coffee](https://buymeacoffee.com/betterstreamflix) · [GitHub Sponsors](https://github.com/sponsors/dskja)
```

4. Strings zurücksetzen:

**EN** `settings_buy_me_a_coffee_summary`: `Support BetterStreamflix development`  
**DE** `settings_buy_me_a_coffee_summary`: `Unterstütze die Entwicklung von BetterStreamflix`  
**EN** `settings_github_sponsors_summary`: `Support BetterStreamflix on GitHub Sponsors`  
**DE** `settings_github_sponsors_summary`: `BetterStreamflix über GitHub Sponsors unterstützen`

5. In `docs/FUNDING_CAMPAIGN.md` Status auf `erreicht` setzen  
6. Funding-Issue schließen
